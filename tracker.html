Pan is a true compass bearing from the camera mast (0° = north). Zoom is approximate until the camera's real zoom curve is measured; the north offset and tilt get calibrated on install day. Ship length comes from AIS — "est." means unknown or a tug pushing a barge, so a typical freighter length is used. Uses the same ship rules as the current camera cue, including the Shepler's before-1-PM rule and the Pause switch on /ptz-log.
